# Portfólio • Lucas Pedroso

Portfólio profissional e interativo focado em Engenharia de Produção, Automação de Processos e Desenvolvimento de Sistemas Sob Medida.

## 🚀 Demonstrações Interativas Inclusas

1. **Controle de Caixa (`#/demo-caixa`)**
   - Gestão de fluxo financeiro empresarial, controle de entradas, saídas, formas de pagamento, saldo consolidado e exportação de relatório limpo em PDF/A4.

2. **Organizador de Arquivos Windows (`#/demo-organizador`)**
   - Simulação imersiva de área de trabalho e explorador de arquivos do Windows 11 com automação de organização de arquivos em lote e tutorial guiado.

3. **Kanban de Tarefas (`#/demo-kanban`)**
   - Gestão visual de fluxos de trabalho com 4 etapas temáticas, atribuição de responsáveis, datas de entrega, prioridades e navegação em carrossel horizontal adaptada para mobile.

## 🛠️ Tecnologias Utilizadas

- **React 19**
- **TypeScript**
- **Vite**
- **Tailwind CSS**
- **Lucide React**

## 💻 Como Rodar o Projeto

```bash
# Instalar dependências
npm install

# Iniciar servidor local
npm run dev
```
